# Arithmetic expression grammar
# Supports: addition, multiplication, parentheses, identifiers
# Examples: id, id + id, id * id + id, (id + id) * id
# Non-terminals: E, T, F (uppercase)
# Terminals: +, *, (, ), id (operators and lowercase)
# Start symbol: E (first production LHS)

E -> E + T
E -> T
T -> T * F
T -> F
F -> ( E )
F -> id
